# 📚 실전 원어민 표현 노트 (일·영 회화 마스터 2,000선)

원어민들이 일상과 애니·미드에서 실제로 쓰는 2,000개 고유 회화 표현 플래시카드 & 퀴즈 학습 웹앱입니다.

## ✨ 주요 기능
- 🇯🇵 일본어 1,000선 + 🇺🇸 영어 1,000선 (총 2,000개 실전 회화)
- 10대 핵심 테마 (리액션, 스몰토크, 감정, 식당, 쇼핑, 길찾기, 호텔, 친구·연애, 슬랭, 긴급 상황)
- 순수 한자 1:1 루비(후리가나) 표기 및 원터치 발음 ON/OFF 토글
- 고양이(일본어) & 독수리(영어) 듀얼 캐릭터 육성 RPG 시스템
- 실전 A·B 티키타카 대화 예문 및 현지 뉘앙스 해설
- 모바일 PWA 완벽 지원 (홈 화면에 앱으로 추가 가능)
